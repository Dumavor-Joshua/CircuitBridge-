This panel uses the open-source CircuitJS simulator for live circuit behaviour, component editing, and animated voltage/current display. It is an independent engine embedded from its public website.

Requires an internet connection. If the simulator does not appear inside this page, use “Open simulator in new tab”. CircuitJS is a separate open-source project; see its source repository and license before redistributing or bundling its code.
